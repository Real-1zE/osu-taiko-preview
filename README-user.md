# osu!taiko 谱面预览器

在 osu! 谱面页上直接预览这张谱的 **osu!taiko 画面**，不用切账号、不用改难度、不用下载谱面。

浏览器扩展，Chrome / Edge 都能用。

## 它做什么

打开任意 osu! 谱面页，右下角会出现一个小窗口：

- **画面预览** —— 音符按 osu!taiko 的方式画出来，Don/Kat 分色、大音符、连打、转盘都在
- **Star Rating 与技能占比** —— 体力/颜色/节奏/读谱四项，以及最大 PP
- **段位与键型** —— 另一个独立的难度体系（详见下文）
- **可勾 mod** —— 变速（HT/DT）与难度（EZ/HR），星数按官方口径随之变化
- **窗口可拖动、可缩放**，位置和大小会被记住
- **画面内可拖动** —— 拖着看全谱

支持：

| | |
|---|---|
| `osu.ppy.sh`（官网） | ✅ |
| `osu.ppy.sb` / `osu.ri.mk` 等 Bancho 系私服 | ✅ |
| osu!（std）谱 | ✅ 自动转成 taiko 视角显示，并标注「转谱」 |
| osu!mania / osu!catch 谱 | ❌ 不显示窗口（转出来的画面和实际玩法差太远） |

## 安装

### 方式一：下载 zip（推荐）

1. 从 [Releases](../../releases) 下载最新的 `osu-taiko-preview-*.zip`
2. 解压到一个**不会被清理的目录**（比如 `工具/osu-taiko-preview`）
   —— 别直接放下载目录，浏览器可能跟着清理
3. 地址栏打开：
   - Chrome → `chrome://extensions`
   - Edge → `edge://extensions`
4. 右上角打开**「开发者模式」**
5. 点**「加载已解压的扩展程序」**，选中刚才解压出来的目录
6. 打开 osu! 任意谱面页，窗口自动出现

### 方式二：商店安装

暂未上架 Chrome Web Store。

### 前置依赖

**没有。** 不需要 Node.js、不需要 npm install、不需要 Python、
不需要起本地服务、不需要联网（除了读取 osu! 自己的谱面文件）。

解压即用。

## 更新

1. 下载新版本的 zip
2. 解压**覆盖**原来的目录
3. 回到扩展页，点插件卡片上的刷新图标

不用重装，也不用删旧的。

> 覆盖时如果多出旧文件（目录结构变了），把原目录删掉重新解压更稳妥。

## 常用操作

| 操作 | 效果 |
|---|---|
| 拖动标题栏 | 移动窗口 |
| **双击标题栏** | 恢复默认大小（尺寸被拖乱了时的救急口） |
| 拖窗口右下角 `◢` | 缩放窗口 |
| 在画面里拖动 | 查看全谱的不同位置 |
| 拖右侧竖条 | 快速滚动 |
| 工具条的复选框 | 开关信息栏 / 小节线 / SV 线 / 轨道底 / 段位行 |
| mod 区的 `+` | 展开全部 mod |

设置（窗口位置、大小、各个开关、mod 选择）都存在本地，换电脑不会同步——
这是有意为之，不上传任何数据。

## 段位 / 键型是什么

除了 osu! 官方的 Star Rating，这套工具还显示另一个独立的难度体系
（来自 [dan_rank](https://github.com/) 项目的移植实现）：

- **段位** —— 1 ~ 10 段显示为 `Reform 1` ~ `Reform 10`，
  10 段以上是 `Alpha` / `Beta` / `Gamma` / `Delta`（带 `+` / `-` 分度），
  低于 1 段显示 `< Reform 1`
- **键型** —— 描述这张谱「难在哪」：大串 / 高速 / 协调 / 复合。
  段位 ≤6 时不标定键型（显示为空是正常的）

它和 Star Rating **互不影响**，两套数值都会同时显示。

> 这部分是独立实现，与 osu! 官方无关，数值口径可能与官方不同。
> 它的作用是给另一个维度的参考，不是替代 Star Rating。

## 常见问题

**窗口没出现？**
- 确认当前是**谱面页**（有 `/osu/<id>` 或 `/beatmapset/<id>`），不是商店页
- mania / catch 谱**不会**显示（不支持）
- 切到这类谱之后，窗口会隐藏；切回支持的谱会再出现
- 页面刚加载时扩展还没注入，**刷新一下**就好

**读不到谱面？**
- 扩展需要联网读取 osu! 的 .osu 文件
- 如果谱面刚被删除或设为未公开，可能读不到

**std 谱上的星数和我在 osu! 网页上看到的不一样？**
- 工具条里能关掉或打开各类辅助线，也能在 mod 区调整变速与难度 mod。
  开 DT / EZ 会让星数变化，这是官方口径。

**我改了 mod，为什么标题栏的星数后面跟了个括号？**
- 那是「与不加这些 mod 时的星数之差」，比如 `10.24 (+1.23)`。
  关掉 mod 它就会消失。

**段位那行能关掉吗？**
- 能。工具条里「轨道底」右边就是它的开关，状态会记住。

## 已知限制

- 只支持 Chrome / Edge 等 Chromium 系浏览器（用了 Manifest V3）
- Firefox 不支持（还没做）
- 窗口里的画面是**静态预览**，不能播放、不能跟着音频滚动
- 段位（Reform / Alpha 那套）是独立实现的社区算法，不是 osu! 官方评级
